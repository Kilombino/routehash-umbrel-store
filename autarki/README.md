# Autarki

One wallet and one shop. Umbrel builds this app from the binaries in `bin/`. It does not pull an image from a registry.

Source: https://github.com/RouteHash-com/autarki

This folder is part of the RouteHash community store. It is not a listing in the official Umbrel App Store.

## Check the files

`SHA256SUMS` lists the program and the install files. From this directory:

```
sha256sum -c SHA256SUMS
```

Each line ends in `OK` when that file matches.
